Kepatuhan Pasar IndonesiaLokal Ready
  • Rupiah Utuh (BIGINT): Tanpa float/desimal; format Rp50.000.000 dengan tabular-nums.
  • 3 Zona Waktu Nusantara: Simpan TIMESTAMPTZ, tampilkan eksplisit WIB / WITA / WIT per event.
  • Pembayaran SaaS Lokal: Integrasi Midtrans/Xendit untuk QRIS & Virtual Account BCA, Mandiri, BRI, BNI.
  • UU PDP No. 27/2022: Minimasi field pendaftaran, akses PII terbatas per izin, dan template bebas data peserta.
Kenapa NestJS Fastify + Prisma v7?Backend Power
  • Fastify Adapter: Throughput JSON lebih tinggi & hemat RAM saat lonjakan scan QR pagi hari acara.
  • Multi-file Prisma Schema: File 01..07.prisma memisahkan tabel BE-1 & BE-2 tanpa konflik merge.
  • nestjs-zod + Swagger: Validasi input + tipe TypeScript + dokumentasi API /docs lahir dari 1 skema Zod.
  • BullMQ + Redis: Kirim ribuan email/WA tiket & pengingat H-3 tanpa membuat API lambat.
Stack Lokal 1 Perintah (Docker)Gratis 100%
  • PostgreSQL 17: Database relasional + constraint unik anti-double check-in.
  • Redis 7: Antrean BullMQ, throttling login/daftar publik, & pub/sub live ops.
  • MinIO (Port 9000/9001): Simulasi Cloudflare R2 lokal untuk upload poster, proposal & nota.
  • Mailpit (Port 8025): Menangkap email undangan & e-ticket QR lokal tanpa perlu domain SMTP berbayar.
